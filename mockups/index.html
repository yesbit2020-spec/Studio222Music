STUDIO 222 MOCKUPS

構築専用プレゼンテーション画面 / デザイン設計とコンセプトの比較

01

Initial Dashboard

Concept / 設計意図

プロジェクト初期に構築された、管理画面・ダッシュボード寄りのUIデザイン。 多数のコンテンツを整理・分類して一覧表示することに特化しており、機能性と情報の一覧性を重視しています。

Key Features / 特徴

  • 情報密度の高いグリッドレイアウト
  • アプリライクなヘッダーとナビゲーション
  • 各コンテンツの情報をシンプルに一覧化
02

Promotional LP (YouTube Focus)

Concept / 設計意図

訪問者を「YouTubeでの視聴」へ強く誘導するための、プロモーション特化型ランディングページ。 大きなヒーロービジュアルと、没入感のあるセクションごとの展開により、音楽の世界観を視覚的に伝えます。

Key Features / 特徴

  • 画面全体を使った没入型ヒーローセクション
  • 目立つYouTube誘導ボタン（CTA）
  • サムネイル上の再生ボタンUIによる動画感の演出
  • カテゴリごとの世界観を表現したダイナミックなセクション
03

Modern Dark LP (v2)

Concept / 設計意図

02案の「YouTube誘導」という目的を継承しつつ、デザインをより洗練された「プレミアムなダークモード」へと昇華させました。 抽象的なオーディオ波形とダークブルー・パープルのグラデーションを用いて、プロフェッショナルなレコーディングスタジオのクオリティと没入感を演出しています。

Key Features / 特徴

  • プレミアムなタイポグラフィと画像置換対応のロゴ構造
  • JavaScript連動のカテゴリフィルター（タブ切り替え）機能
  • ホバー時にグロウ（発光）エフェクトを放つカードUI
  • SNSアイコンと、隠し味として配置されたAdminリンク
